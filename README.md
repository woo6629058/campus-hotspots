## 2주차: HTML과 페이지 연결

### 소개 장소

1. **니콜스관 4층 카페 하랑** — 넓은 창가에서 공부하거나 쉬기 좋은 곳
2. **하늘동산** — 벚꽃과 계절의 변화를 느끼며 산책하기 좋은 곳
3. **베리타스관 중앙도서관** — 시험과 과제를 준비하며 조용히 집중하기 좋은 곳

추천 방문 순서는 니콜스관 4층 카페 하랑 → 하늘동산 → 베리타스관 중앙도서관입니다.

### 페이지 구성

- `index.html`: 세 장소와 추천 방문 순서를 소개하는 프론트페이지
- `cafe-harang.html`: 니콜스관 4층 카페 하랑 상세 페이지
- `haneul-garden.html`: 하늘동산 상세 페이지
- `veritas-central-library.html`: 베리타스관 중앙도서관 상세 페이지
- `styles.css`: 네 페이지의 공통·페이지별·모바일 스타일
- `images/`: 홈페이지에서 사용하는 장소 사진

## 3주차: CSS와 반응형 UI

### 페이지별 스타일

- 프론트페이지: 추천 방문 순서를 색으로 따라갈 수 있도록 `page-home`에 하랑의 흰색·크림·베이지와 은은한 캐러멜, 하늘동산의 벚꽃·연두, 중앙도서관의 회백·푸른 회색·남색이 위에서 아래로 이어지는 그라데이션을 적용했습니다. 제목 글자에도 흰색에서 벚꽃색까지 이어지는 그라데이션을 사용하고 배경에는 부드럽게 흐르는 색 띠를 더했으며, 각 장소 카드는 장소 분위기에 맞는 강조색과 둥근 모서리, 부드러운 그림자로 구분했습니다.
- 니콜스관 4층 카페 하랑: 햇빛과 원목 가구의 포근함을 표현하기 위해 `page-cafe`에 크림·캐러멜 계열 그라데이션과 커피 김을 닮은 곡선 장식, 둥근 모서리와 부드러운 그림자를 적용했습니다.
- 하늘동산: 벚꽃과 새잎이 보이는 계절감을 표현하기 위해 `page-garden`에 하늘색·분홍색·연두색 그라데이션과 원형 빛, 유기적인 모서리와 부드러운 간격을 적용했습니다.
- 베리타스관 중앙도서관: 조용한 열람실의 차분함을 표현하기 위해 `page-library`에 회백색에서 푸른 회색을 거쳐 짙은 잉크색·남색으로 선명하게 이어지는 그라데이션과 책장을 닮은 얇은 직선 패턴, 명조 계열 글꼴과 반듯한 테두리를 적용했습니다.

### 모바일 스타일

- 적용한 `@media` 조건: 화면 너비 `640px` 이하
- 모바일에서 특별히 바뀌는 부분과 이유: 모바일에서는 본문과 카드의 여백, 제목과 소개 글의 크기를 줄이고 링크의 높이와 너비를 늘려 누르기 쉽게 만들었습니다. 모든 이미지는 화면 너비를 넘지 않으면서 원본 비율을 유지합니다.
- 휴대전화 확인 결과: 네 페이지 모두 한 열로 표시되며 가로 스크롤 없이 이미지와 링크를 사용할 수 있습니다.

### 실습 1

- 내가 수정한 부분: 2주차에 고른 카페 하랑, 하늘동산, 베리타스관 중앙도서관의 사진·설명·추천 활동을 한 화면의 세 `section`에 모았습니다. 장소 선택 버튼은 JavaScript에서 만들고, 첫 접속에는 카페 하랑이 선택되도록 했습니다.
- 버튼 클릭 → 내용 변경 → 지도 변경의 흐름: `app.js`의 `selectPlace()`가 선택하지 않은 `section`에는 `hidden`을 적용하고, 버튼의 `aria-pressed`를 바꾼 뒤 Google 지도 `iframe`의 `src`와 제목, 새 창 링크를 같은 장소 정보로 교체합니다.
- 휴대전화에서 확인한 결과: 화면 너비 390px에서 버튼·설명·사진·지도가 한 열로 표시되고 가로 넘침 없이 장소 세 곳을 전환할 수 있습니다.

### 실습 2

- 데이터 출처 URL / 내려받은 날짜: [공공데이터포털 · 전국도서관표준데이터](https://www.data.go.kr/data/15013109/standard.do) / 2026년 9월 21일
- 데이터 선택 이유 / 대상·기간·단위: 공부 장소와 연결되는 공공도서관의 지역별 차이를 살펴보기 위해 선택했습니다. 서울특별시 204개관, 인천광역시 119개관, 경기도 307개관으로 총 630개관이며 기관별 데이터기준일자는 CSV에 함께 보존했습니다. 그래프 단위는 개관과 %입니다.
- 그래프 1: “공공도서관이 많은 시군구는 어디인가?” / `시도명`, `시군구명`, `도서관명` / 지역 이름이 길고 여러 시군구를 비교하기 쉬운 가로 막대그래프 / 서울·인천·경기 버튼을 누르면 선택 지역의 모든 시군구 집계와 해석이 함께 바뀝니다.
- 그래프 2: “평일 21시 이후 운영하는 도서관 비율은 시군구별로 어떻게 다른가?” / `시도명`, `시군구명`, `평일운영종료시각` / 시설 수가 다른 시군구를 공정하게 비교하기 위한 비율 가로 막대그래프 / 표준 시각 열이 21:00 이상인지 비교하며, 실제 방문 가능 시간은 각 도서관의 최신 안내를 확인해야 합니다.
- 필터링·집계·결측치 처리: 전국 자료에서 `시도명`이 서울·인천·경기이고 `도서관유형`이 공공도서관인 행만 남겼습니다. 시군구명과 도서관명이 없는 행은 전체 분석에서 제외하고, 평일 종료 시각이 비어 있거나 올바른 `HH:MM` 형식이 아닌 행은 두 번째 그래프의 분모에서만 제외합니다. 결측치를 임의로 0으로 바꾸지 않습니다. 집계할 때 시군구명의 불필요한 접두어·공백과 명백한 오타 1건을 정리합니다.
- 지역·탭 전환 방식: `data-region` 버튼으로 서울·인천·경기 행을 고른 뒤 두 그래프와 해석을 다시 계산합니다. `data-panel`과 `section`의 `id`를 연결해 선택한 그래프만 보이게 하고, 두 버튼 그룹 모두 `aria-pressed`로 선택 상태를 알립니다. 숨겨진 그래프를 표시한 뒤 `requestAnimationFrame()`에서 차트 크기를 다시 맞춥니다.
- 휴대전화에서 지역 버튼과 두 탭을 확인한 결과: 화면 너비 390px에서 버튼, 그래프 범례·축, 해석과 출처가 화면 밖으로 나가지 않고 세로로 읽힙니다. 경기도의 31개 시군구는 그래프 높이를 항목 수에 맞게 늘려 이름이 겹치지 않게 했습니다.
- 빈 데이터·잘못된 CSV를 넣었을 때 결과: 파일 요청 실패, 필수 열 누락, CSV 해석 오류, 선택 지역에 분석 가능한 행이 없는 경우 그래프 대신 상태 영역에 원인과 확인할 항목을 표시합니다.
- Codex 활용: 공개 표준데이터의 지역 필터링, CSV 집계·지역 선택·탭 전환·오류 처리를 구성하는 데 도움을 받았습니다. 대표 질문은 “`시도명`, `시군구명`, `평일운영종료시각` 열을 사용해 서울·인천·경기의 시군구별 도서관 수와 21시 이후 운영 비율을 계산하고, 결측치를 0으로 만들지 않는 Chart.js 화면을 작성해 줘”였습니다. 원본 630개 행과 지역별 집계값을 직접 대조하고, 지역·탭 전환과 오류 메시지를 브라우저에서 검증했습니다.

### 실습 3

- 게임 이름 / 아이디어 / 조작과 규칙: **별자리 산책로 미니 게임**. 밤의 캠퍼스에 흩어진 별을 1번부터 순서대로 선택해 빛나는 길을 완성하는 30초 게임입니다. 별 하나를 연결하면 +100점, 별자리를 완성하면 단계별 보너스를 받습니다. 순서를 틀리면 기회가 하나 줄고, 기회 세 개를 잃거나 30초가 지나면 끝납니다. 마우스와 터치로 조작합니다.
- Codex 활용: “HTML Canvas와 JavaScript로 밤의 캠퍼스에 흩어진 별을 번호 순서대로 연결하는 게임을 만들어 줘. 마우스·터치를 지원하고 점수·시간·기회·단계, 종료 결과와 재시작을 보여 줘. 단계가 올라갈수록 연결할 별을 늘리고 재시작할 때 이전 애니메이션을 정리해 줘.”
- 추가 수정 요청과 개선한 점: 별을 단순히 누르는 데서 끝나지 않도록 연결된 별 사이에 빛나는 선을 그리고, 다음 별에는 맥동 효과와 마우스를 따라가는 점선을 표시했습니다. 단계를 완성하면 별 개수가 하나씩 늘어나고 보너스 점수를 받도록 개선했습니다.
- 직접 확인한 동작: 번호 순서 선택, 별과 연결선 표시, 정답 점수 증가, 잘못된 순서의 기회 감소, 단계 전환, 30초·기회 소진 종료, 다시 시작할 때 점수·시간·기회·단계와 애니메이션 초기화를 확인했습니다.
- 휴대전화에서 확인한 결과: Canvas가 화면 너비에 맞게 축소되며 별을 손가락으로 누를 수 있고, 넓은 터치 판정 범위를 사용해 작은 화면에서도 선택하기 쉽습니다. Canvas 내부를 누를 때 의도하지 않은 화면 스크롤도 발생하지 않습니다.
- 이미지·소리 출처와 이용 조건: 외부 이미지와 소리를 사용하지 않고 Canvas 도형과 글자로 직접 표현했습니다.
